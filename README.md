# ChatGPT 订阅与充值检查指南

一份面向中文用户的操作检查清单，帮助你在购买前确认账号与服务条件，在付款后核对订单与会员状态。

本项目由 [MY-GPT NET](https://my-gpt.net/) 维护。维护者经营第三方充值服务，与 OpenAI 无官方隶属关系。本指南不构成官方支持或服务保证。

## 一、购买前检查清单

- [ ] 确认实际使用的账号邮箱，避免混淆多个登录账号。
- [ ] 查看当前是否已有订阅，以及原订阅是否仍在自动续费。
- [ ] 核对所购套餐、服务时长、适用条件和最终金额。
- [ ] 阅读处理时间、失败处理方式、退款条件及隐私说明。
- [ ] 保存服务方的订单查询入口和售后联系渠道。
- [ ] 对已有订阅、续费或套餐变更存在疑问时，先确认是否适用，再付款。

不要仅凭“低价”“秒到”等宣传判断服务是否适合自己，应以实际服务条件为准。

## 二、付款后如何确认

分别检查以下三个环节：

| 检查环节 | 核对内容 |
| --- | --- |
| 支付记录 | 是否实际扣款、金额是否一致 |
| 服务方订单 | 是否已记录付款、当前处理状态是什么 |
| 账号订阅 | 登录正确账号，查看当前会员状态 |

支付成功、订单完成和会员显示是不同环节，不能只凭其中一个状态判断整个流程已经结束。

保存订单号与支付记录。原订单状态不明确时，先查询或联系服务方，避免重复付款。

## 三、常见异常排查

### 已扣款，但订单显示待支付

1. 核对支付记录中的金额与时间。
2. 返回原订单查询最新状态。
3. 若仍不一致，联系服务方核查。
4. 未查清原订单前，不要重复付款。

### 订单完成，但会员没有变化

1. 确认当前登录邮箱与充值账号一致。
2. 刷新页面，必要时重新登录。
3. 检查账号内显示的订阅状态。
4. 若仍不一致，向服务方提供订单号和经过脱敏的截图。

### 账号已经有订阅

先核对现有套餐、有效期和原订阅渠道，再询问服务方是否支持当前状态。不要默认新订单一定会叠加时长或替换原套餐。

## 四、账号资料安全

以下内容不应出现在公开仓库、Issue、评论区或截图中：

- 账号密码、验证码和恢复码
- Session JSON、Cookie 和访问令牌
- 完整支付凭证及个人联系方式
- 可直接访问订单的私密查询链接

部分资料即使不是密码，也可能允许他人访问账号。提交任何账号验证资料前，应先确认接收方、使用目的及保存方式。
